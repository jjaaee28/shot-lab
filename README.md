# 촬영 구도 실험실

베이지 배경과 검은 선으로 표현한 책 읽는 인물의 3D 촬영 목업입니다.
Next.js + React + Three.js. 서버 데이터, 계정, API 키, 외부 영상 없이 작동합니다.

## 실행

이 Windows 컴퓨터에서는 `start-local.cmd`를 더블 클릭하세요.
터미널에 표시되는 Local 주소(기본 http://127.0.0.1:3000)를 브라우저에서 엽니다.
종료하려면 실행 창에서 Ctrl+C를 누릅니다. 포트 3000이 사용 중이면 기존 실행을 종료하거나 다른 포트로 실행하세요.
실행 스크립트는 설치된 Node.js 또는 이 컴퓨터의 Codex 번들 Node.js를 사용합니다.

일반적인 개발 환경에서는 Node.js 20.9 이상을 설치한 뒤:

```sh
npm install
npm run dev
```

다른 포트 사용: `npm run dev -- --port 3001`
배포용 빌드 확인: `npm run build`
빌드 실행: `npm start`
재현 가능한 설치에는 pnpm과 포함된 pnpm-lock.yaml을 사용합니다: `pnpm install --frozen-lockfile`.

## 사용법

1. 촬영 방법 둘러보기를 누릅니다.
2. 고정 촬영에서 기본 각도 네 개(정면, 반측면, 측면, 뒷모습)를 선택합니다.
3. **카메라 회전**: 장면을 좌클릭 드래그하거나 키보드 방향키(←, →, ↑, ↓)로 360도 수평 회전 및 상하 각도(하이앵글~로우앵글)를 조절합니다.
4. **인물 프레이밍(Truck)**: 우측 컨트롤의 `03 인물 프레이밍`에서 가로·세로 위치와 슬라이더를 조절하거나, 장면 위에서 **마우스 우클릭 드래그**(또는 Shift + 드래그)합니다. 좌우 드래그는 인물의 가로 위치, 위아래 드래그는 세로 위치를 바꿉니다.
5. **3분할 구도선**: 뷰어 상단의 `# 3분할 선` 버튼을 켜서 시네마틱 삼분할 법칙(Rule of Thirds)에 맞게 인물이 걸치는지 확인합니다.
6. **카메라 줌**: 마우스 휠 스크롤 또는 우측 줌 슬라이더, +/− 버튼으로 줌 인/아웃(0.5x~3.0x)을 자유롭게 조절합니다.
7. **이동 촬영**: 달리 인·아웃(각 5초), 아크 샷(시계·반시계 방향, 각 10초)을 선택해 원하는 방향으로 회전시키며 관찰합니다.

## 스크립트 → 3D 데모

시작 화면에서 `스크립트로 장면 만들기`를 누르면 두 번째 화면에서 촬영 스크립트를 작성할 수 있습니다. `AI 장면 그리기 (데모)`는 실제 AI/API를 호출하지 않고, 준비된 책 읽는 인물 장면을 연결해 실험 화면으로 이동합니다. 입력한 스크립트는 현재 브라우저 상태에서만 사용합니다.
8. 일시정지, 계속 재생, 처음부터를 눌러 움직임을 관찰합니다.
9. 재생 중 드래그하면 정지하고 새 방향을 설정합니다. 새 방향에서 처음부터 재생합니다.

회전은 수평 360도 및 상하 각도(하이앵글~로우앵글) 조절을 모두 지원하며, 프레이밍 위치와 줌 배율(0.5x~3.0x)도 실시간으로 하단 캡션에 함께 표시됩니다.
아크 샷은 시계 방향과 반시계 방향을 선택할 수 있으며, 현재 설정된 시작 각도, 높이, 프레이밍 위치를 유지하면서 인물 주변을 360도 회전합니다. 뒤에서는 인물 뒷모습과 의자에 책이 가려지는 것이 정상입니다.

## 구조

- app/page.js: 화면, 입력, 재생 상태
- app/scene.js: 기본 도형 장면과 카메라 계산
- app/globals.css: 반응형 베이지·검정 디자인
- PRD.md: 확정한 기획과 구현 범위
- VALIDATION.md: 실제 수행한 검증과 한계

## 범위

실제 촬영이나 영상 생성 결과가 아닌 구도 이해용 가상 애니메이션입니다.
조명, 렌즈 왜곡, 실사 인물 표현은 구현하지 않았습니다. WebGL을 지원하는 브라우저가 필요합니다.
네트워크는 최초 패키지 설치에 필요하며 앱은 외부 데이터나 외부 이미지를 불러오지 않습니다.
배포하지 않았습니다.
